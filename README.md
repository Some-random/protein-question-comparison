# Protein question comparisons

Compare original protein multiple-choice questions with skill-informed rewrites and saved Flash-Next responses. Each question is shown beside its rewrite, with the full responses underneath. Expand the sections to see the protein sequence and generated reasoning.

- **10,000** original questions; **9,547** skill-informed rewrites.
- **9,988** original responses; **9,522** rewrite responses; **9,510** questions have both.
- Both response sets were generated by Flash-Next with task helpers. Responses are model-generated and have not been independently verified; missing rewrites or responses are labeled.
- [Open the interactive question explorer](https://www.jiangdongwei.com/protein-question-comparison/).
