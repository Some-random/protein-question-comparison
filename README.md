# Protein Question Explorer

A static comparison of 10,000 original protein multiple-choice questions, 9,547 skill-informed rewrites, and saved Flash-Next responses. Both sets of responses were generated with task helpers. There are 9,510 questions with responses for both versions. Missing material is labeled in the interface.

The responses and expandable generated reasoning are model outputs and have not been independently verified. They are not source answer keys. Question types and skill IDs come from the corresponding source records. The 100 JSON shards contain only the public display fields used by the page.
